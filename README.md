# Compte rendu – Initiation au développement Web

Au cours de ces activités, j'ai appris les bases du développement Web :

  HTML : structurer une page Web avec les différentes balises et créer des formulaires.\
  CSS : mettre en forme une page, gérer les couleurs, les polices et la disposition des éléments.\
  JavaScript : manipuler les variables, les fonctions, les événements et le contenu HTML.\
  Stockage : utiliser localStorage pour conserver des données dans le navigateur.\
  Alpine.js : découvrir la gestion des données et des interactions directement dans le HTML.\
  Utiliser x-data, x-model, x-for et x-on pour rendre une page dynamique.\
  Gérer les préférences utilisateur, comme le thème sombre et la police adaptée à la lecture.
